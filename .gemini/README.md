# Gemini / Antigravity Config

This folder contains optional Gemini or Antigravity client configuration only.

- `.gemini/antigravity/mcp_config.json` points the client at the local Unity MCP endpoint.
- Project rules live in the repository root `AGENTS.md`.
- Active reusable skills live in the repository root `skills/`.
- Do not add project rules or active skills under `.gemini/`.
