# Skills

Active agent skills for Unified Unity MCP.

These skills are workflow guides, not global policy. Global project rules live in the repository root `AGENTS.md`.

## Core Skills

- `unified-unity-mcp` - use the Unity MCP server and keep tool docs synchronized
- `csharp-code-style` - apply the repository C# style
- `unity-csharp-fundamentals` - write safe Unity components and editor code
- `unity-developer` - implement Unity features in the package style
- `unity-testrunner` - run and interpret Unity tests

## Focused Skills

- `csharp-async-patterns` - async, cancellation, and Unity main-thread boundaries
- `csharp-xml-docs` - concise XML docs for public APIs
- `unity-async` - Unity coroutines, tasks, editor polling, and main-thread work
- `unity-collection-pool` - use `UnityEngine.Pool` on measured hot paths
- `unity-performance` - profile and optimize Unity projects
- `unity-mobile` - mobile-specific checks for target Unity projects
- `unity-ui` - UGUI and UI Toolkit implementation guidance
- `unity-ui-creator` - create uGUI screen hierarchies
- `unity-ui-layout-automation` - validate UI layout structure
- `unity-textmeshpro` - TextMeshPro setup and text performance
- `csharp-pro` - general C# refactoring support aligned to repo style
- `skill-creator` - create or update skills

## Maintenance Notes

- Keep active `SKILL.md` files concise and current.
- Use `references/` only for details that still match `AGENTS.md`.
- If a reference contains old examples, treat it as background and update it before using it as task guidance.
- Tool names and arguments must match `Assets/ThirdParty/UnifiedUnityMCP/Editor/active_tools.json` or `ToolsCatalog.md`.
